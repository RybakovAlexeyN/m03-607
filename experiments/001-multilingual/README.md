# Experiment 001 — Руслан и Людмила × 5 languages

Цель: проверить подготовку рукописных страниц А4 для 5 языков/типов письменности на **одном смысловом фрагменте**.

## Corpus

Source: [«Руслан и Людмила» (Пушкин), пролог](https://ru.wikisource.org/wiki/Руслан_и_Людмила_(Пушкин)), первые 18 стихотворных строк, включая строку авторства **ровно 500 Unicode-символов**.

| Язык | Код | Символы в текстовом файле | Направление |
|---|---|---:|---|
| Русский | `ru` | 500 | LTR, кириллица |
| English | `en` | 651 | LTR, латиница |
| Français | `fr` | 702 | LTR, латиница с диакритикой |
| العربية | `ar` | 540 | RTL, арабское письмо |
| 日本語 | `ja` | 254 | японские знаки, возможная вертикальная композиция |

Переводы подготовлены заново; длины различаются, но смысловой фрагмент один. Нельзя сравнивать символы между языками напрямую без поправки на различия систем письма.

## Воспроизвести подготовку

```bash
for lang in ru en fr ar ja; do
  python3 handwriting-notes/scripts/pagepack.py prepare \
    "experiments/001-multilingual/source/${lang}.txt" \
    --out "experiments/001-multilingual/build/${lang}" \
    --layout single_column --mode precision --max-chars 1300
  python3 handwriting-notes/scripts/pagepack.py verify \
    "experiments/001-multilingual/build/${lang}"
done
```

Workflow: [multilingual-benchmark.yml](../../.github/workflows/multilingual-benchmark.yml). It runs unit tests, all 5 pagepack preparations, lossless checks and Russian length validation. CI success must be verified in the **Actions** tab; creating the workflow does not prove that it has completed successfully.

## Interim experiment findings

- ImageGen generated an attractive Russian cursive A4 page, but in other attempts **ignored single-language requests** and generated multilingual collages with truncated / reformulated content.
- A deterministic font-based baseline was separately produced for five scripts to preserve source control and compare with ImageGen. **It is not imitation of the exact online authors' handwriting**, and it is not generated by `pagepack.py` alone.
- Source and prompt integrity can be checked automatically. Text accuracy inside generated images still needs manually reviewed transcriptions and CER.
- Recommended next v0.2 architecture: Unicode-aware page packing → writer-consented style profile → script-aware rendering → manual transcription comparison and blind similarity rating.

**Scope and ethics:** do not upload classmates' personal handwriting to a public repository; do not pass generated coursework off as physically handwritten where academic rules require genuine manuscript work.
